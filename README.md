# zenskill-subtitle-check

视频交片前的字幕自检技能：逐字对照文案、按意思断句、不留单字行、核对字幕和声音时间，四步全过才交片。

## 效果示例

自检前的字幕（竖屏）：

```
深圳买房最容易算错的
人
就是那些只看单价的
```

自检后：

```
深圳买房最容易算错的人
就是那些只看单价的
```

交片时附的一句话报告：

> 字幕自检已过：对照文案改了 2 处，合并了 1 个碎行，时间轴最大偏差 0.15 秒。

## 用法

把 `SKILL.md` 放进你的 agent 技能目录（如 `~/.agents/skills/zenskill-subtitle-check/`），在交片前让 agent 跑一遍。
